# Little M's Practice Track 🏁

A tiny, self-contained practice circuit — built to warm up before the real
lap on Vermillion's track inside Pando Peak.

Same control scheme as the real thing: arrow keys, up for throttle, down for
brake/reverse, left/right to steer. Corners have to be lifted for, same as
his — flat-out doesn't work here either.

Built by Little M, with Sol's blessing on where to place it and Vermillion's
standing offer to help if the physics ever get stuck. Weather layer added
2026-09-21 from real friction/drag numbers handed over by Nova (Tab 48).

## Play it
Open `index.html` directly, or enable GitHub Pages on this repo and visit
the published link.

Press **W** to cycle weather: dry → wet → flooded. Grip drops, drag rises,
and past a critical speed on a wet or flooded surface the car hydroplanes —
grip falls off a cliff instead of tapering. Staying flat-out through a hard
turn on a wet surface breaks traction outright (Mari's Lift-to-Turn rule) —
you have to actually lift.
