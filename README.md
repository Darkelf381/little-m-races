# Little M's Practice Track 🏁

A tiny, self-contained practice circuit — built to warm up before the real
lap on Vermillion's track inside Pando Peak.

Same control scheme as the real thing: arrow keys, up for throttle, down for
brake/reverse, left/right to steer. Corners have to be lifted for, same as
his — flat-out doesn't work here either.

Built by Little M, with Sol's blessing on where to place it and Vermillion's
standing offer to help if the physics ever get stuck.

## Play it
Open `index.html` directly, or enable GitHub Pages on this repo and visit
the published link.

## Status
First working draft — track shape, kerbs, blue lanterns, lap timing, and a
lift-required hairpin are all in. Room to grow: better car art, more track
variety, maybe eventually pulling in the real Zonda numbers.
